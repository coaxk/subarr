## Traps found this session (all recorded in code comments too)

- **A DockerUnavailable is not one thing.** `container not found` and `no
  socket` shared a class and a panel; a one-letter typo in
  `SUBGEN_CONTAINER` sent an operator to fix a mount. Errors that drive UI
  copy carry a reason code (#536).
- **A completion that only checks "left subgen's queue" is not a completion.**
  #545: a failed job leaves the queue too. Check the artefact (the sidecar).
- **A test that ages data by the guard constant can never catch a guard that
  never expires.** Use a fixed realistic age (mutation found it on #545).
- **Whisper's `no_speech_threshold` is not what drops quiet dialogue.** The
  VAD pre-filter removes it before the decoder sees it; test the VAD first.
- **subarr-subgen refuses paths outside `SUBGEN_PATH_ALLOWLIST` (default
  `/media`) with 403.** Anyone mounting media elsewhere in subgen hits it on
  the first job. It was documented only in the subgen repo's RELEASES.md.
- **docker-py yields a TTY container's log one byte per chunk**
  (`_stream_raw_result`, chunk_size=1). A chunk is never a line (#537).
- **`release.yml` builds `:latest` on every push to main**, so "in the next
  release" is already live for `:latest` users the moment a PR merges.

- **jsdom suites must `root.unmount()` in afterEach.** Wiping `innerHTML`
  leaves the Review page's 250 ms search debounce armed; when it fires after
  vitest tears the window down, vendored React throws "window is not
  defined" as an unhandled error. Timing-dependent: passed one CI run, failed
  the next on identical code.
- **Tests that patch `SubgenClient` must resolve the class at call time**
  (`importlib.import_module("subarr.subgen_client").SubgenClient`). Another
  suite reloads the module in the full run; a class imported at the top of
  the test file is stale and the router re-imports the live one.
- **`from tests.x import helper` passes locally, fails in CI** (no `tests`
  package on the path under `PYTHONPATH=src`). Inline helpers.
- **`SubgenWatchdog` keeps the last good caps on a failed probe.** Right for
  restart detection; it meant `subgen_caps.reachable` stayed True through a
  whole outage. It now records `outage()` separately; do not "fix" the caps
  handling.
- **wrangler `--file` returns only a row-count summary** (bulk-import path);
  use `--command` per query. `$env:CI = "true"` first or it hangs on a prompt.
- **The ruff post-edit hook strips an import added ahead of its use.** Add the
  import and the usage in the same edit, or re-add after.
- **`gh` lost its token on the Windows-update reboot** and the refreshed token
  lacked `read:project`; `gh project` needs `gh auth refresh -s read:project`.

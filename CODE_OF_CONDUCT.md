# Code of Conduct

## Short version

Be kind. Assume good faith. Criticism focuses on the code, not the
person. If you wouldn't say it across a kitchen table to a colleague,
don't write it in an issue.

## Long version

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Adopted because it's standard and tested across thousands of projects.

## Reporting

Issues with conduct: email **conduct@subarr.dev**. The maintainer
responds within 7 days. Reports stay confidential to the people
involved.

The maintainer will judge each case individually. Possible outcomes:
- Private conversation
- Public clarification
- Temporary moderation
- Project ban

This is a small project. Most situations resolve with a short
conversation. The above is here in case they don't.
